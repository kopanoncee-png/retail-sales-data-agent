# retail-sales-data-agent

## Project Objective
This project involved building a Retail Sales Data Agent using Databricks to analyse retail transaction data and generate business insights using natural language questions.

## Tools Used
- Databricks
- SQL
- Databricks Genie spaces
- GitHub
- Microsoft Word

## Dataset Overview
The dataset contains retail transaction information including customer demographics, product categories, quantities, pricing, and total transaction amounts.

## Steps Followed
1. Uploaded dataset into Databricks
2. Reviewed dataset schema and column structure
3. Prepared the dataset for analysis
4. Created and configured the Data Agent
5. Wrote custom agent instructions
6. Tested the agent using business questions
7. Validated responses using SQL queries
8. Generated business insights and recommendations

## Sample Questions Tested
- What is the total sales revenue?
- Which product category generated the highest revenue?
- Which age group spends the most?
- Which month performed best in sales?
- Which customers should be targeted for upselling?

## Key Insights
- Electronics generated the highest revenue
- Customers aged 46–55 spent the most overall
- Female customers spent slightly more per transaction
- May 2023 recorded the highest monthly sales

## Conclusion
This project demonstrated how a Data Agent can support business decision making using retail sales data and natural language analytics in Databricks.
